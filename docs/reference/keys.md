# Mouse and keys

Keys act on the view; they do nothing while you are typing in a field. On macOS, ++ctrl++ is
++cmd++.

## Mouse

| Do | To |
|---|---|
| Drag | Orbit |
| Right-drag, or ++shift++-drag | Pan |
| Scroll | Zoom |
| Click | Select (or place, or measure, when those are on) |
| Double-click | Fit everything visible |
| Move over an element | Highlight its edges |
| Drag the view cube | Orbit |
| Click the view cube | Look from that face, edge or corner |
| Drag a section box arrow | Move that face of the box |

In a plan or a section, dragging pans (there is nothing to orbit), or moves the reference plan whose
**Drag it in the view** is on. ++t++, ++o++ and ++b++ do nothing there, and the view cube is hidden.

## Keys

| Key | Does |
|---|---|
| ++f++ | Fit everything visible |
| ++t++ | Top view |
| ++o++ | Perspective / orthographic |
| ++e++ | Edges on / off |
| ++h++ | Hatching on / off |
| ++b++ | Section box on / off |
| ++m++ | Measure on / off |
| ++ctrl+k++ | Command palette: find and run any command |
| ++esc++ | Close the palette; else stop placing; else drop the first point of a dimension; else clear the selection |
| ++shift++ while placing | Don't snap: the point is only rounded to 10 mm |

## Editing (`.bimble` models)

| Key | Does |
|---|---|
| ++ctrl+z++ | Undo |
| ++ctrl+y++, ++ctrl+shift+z++ | Redo |
| ++ctrl+s++ | Save (download, in a browser). With an IFC model: save its views to the side file |
| ++delete++ | Delete the selected element |
