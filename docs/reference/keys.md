# Mouse and keys

Keys act on the 3D view; they do nothing while you are typing in a field. On macOS, ++ctrl++ is
++cmd++.

## Mouse

| Do | To |
|---|---|
| Drag | Orbit |
| Right-drag, or ++shift++-drag | Pan |
| Scroll | Zoom |
| Click | Select (or place, or measure, when those are on) |
| Double-click | Fit everything visible |
| Move over an element | Highlight its edges |
| Drag the view cube | Orbit |
| Click the view cube | Look from that face, edge or corner |
| Drag a section box arrow | Move that face of the box |

## Keys

| Key | Does |
|---|---|
| ++f++ | Fit everything visible |
| ++t++ | Top view |
| ++o++ | Perspective / orthographic |
| ++e++ | Edges on / off |
| ++h++ | Hatching on / off |
| ++b++ | Section box on / off |
| ++m++ | Measure on / off |
| ++esc++ | Stop placing; else drop the first point of a dimension; else clear the selection |

## Editing (`.bimble` models)

| Key | Does |
|---|---|
| ++ctrl+z++ | Undo |
| ++ctrl+y++, ++ctrl+shift+z++ | Redo |
| ++ctrl+s++ | Save (download, in a browser) |
| ++delete++ | Delete the selected element |
